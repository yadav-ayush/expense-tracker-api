# 💸 Expense Tracker API

A secure, JWT-authenticated REST API to track, manage, and report personal expenses — built with **Spring Boot**, **JWT**, **Spring Security**, and **JPA**.

---

## 🚀 Features

- ✅ User Registration & Login (with JWT token)
- ✅ Add, View, Delete Expenses (per user)
- ✅ Filter expenses by date
- ✅ View total expenses for a given range
- ✅ Breakdown by category
- ✅ Monthly expense reports

---

## 🛠️ Tech Stack

- Java 17
- Spring Boot 3.2.x
- Spring Data JPA
- Spring Security
- H2 Database
- JWT (io.jsonwebtoken)
- Lombok
